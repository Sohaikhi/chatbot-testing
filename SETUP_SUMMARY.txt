🚀 JAVASCRIPT SETUP (FROM NEW GUIDE):

1. Install Node.js 18+ and Git
2. Clone repository
   git clone https://github.com/Sohaikhi/chatbot-testing.git
   cd chatbot-testing
3. Install dependencies
   npm install
   npm run install-browsers
4. Verify setup
   npm run validate
5. Run first test
   npm test

Time: 15-30 minutes total

═══════════════════════════════════════════════════════════════════

🚀 C# SETUP (FROM NEW GUIDE):

1. Install .NET SDK 8.0+ and Git
2. Clone repository
   git clone https://github.com/Sohaikhi/chatbot-testing.git
   cd chatbot-testing
3. Run setup script
   ./setup.sh (Linux/Mac)
   .\setup.ps1 (Windows)
4. Run tests
   dotnet test --settings:.runsettings

Time: 15-30 minutes total
